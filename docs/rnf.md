## Requisitos Não Funcionais (RNF)

### RNF01 — Tempo de resposta
O sistema deve fornecer uma resposta rápida a requisições feitas pelo usuário.

### RNF02 — Segurança
As senhas devem ser armazenadas usando hash seguro.

### RNF03 — Compatibilidade
O sistema deve funcionar em quaisquer navegadores de internet.
